# Jarvis. Jarvis es un asistente personal orientado a voz y desarrollo. Su objetivo es permitir que el usuario interactúe mediante voz con herramientas de programación y desarrollo, integrándose progresivamente con Codex, GitHub y Vercel. Objetivos principales:
interacción por voz, asistencia en tareas de programación, integración con Codex, control y versionado de proyectos mediante GitHub, despliegue de proyectos mediante Vercel, uso de skills y mantener una identidad visual coherente con el System Design de su portafolio. Arquitectura prevista: voz, Jarvis, skills, herramientas de desarrollo, GitHub y Vercel
